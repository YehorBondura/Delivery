Delivery System
An educational C++ project demonstrating object-oriented design through a delivery service model.

Features
Three delivery methods: courier, post office, and parcel locker
Inheritance and polymorphism
Abstract classes and virtual methods
Method overriding
Template Method design pattern
Technologies
C++
Object-Oriented Programming (OOP)

Purpose
The project demonstrates how object-oriented programming principles and design patterns can be used to structure a system supporting multiple delivery methods.
